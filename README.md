This project analyzes the historical performance and sectoral rotation of the Indian stock market across 15 sectors from 2006 to 2026 using Microsoft Power BI.

The dashboard helps explore how leadership shifts between sectors over time, which sectors outperform or underperform during different periods, and how sector returns change across 1-year, 3-year, and 5-year investment horizons.

By combining historical market data, annual sector rankings, interactive visualizations, and return calculations, this project transforms complex market information into an intuitive analytical tool.

🎯 Project Objectives

Analyze historical sector performance from 2006 to 2026.

Identify the best-performing and worst-performing sectors each year.

Track changes in sector rankings over time.

Study sectoral rotation across different market cycles.

Compare short-term and long-term sector returns.

Investigate how individual sectors perform during different periods.

Build an interactive dashboard for market research and historical analysis.

📈 Dashboard Features

1. Annual Sector Performance Ranking

A color-coded ranking matrix displays sector performance year by year.

Key features:

Annual ranking of 15 sectors.

Percentage returns for individual sectors.

Identification of top-performing and underperforming sectors.

Visual comparison of sector leadership across years.

Historical observation of sector rotation patterns.

2. Historical Performance Trends

A time-series line chart displays sector performance over the period 2020–2026 in the current dashboard view, with the broader project covering historical data from 2006–2026.

Users can select individual sectors to examine their historical price trends and identify periods of growth, correction, and recovery.

📊 Analytical Approach

The project uses historical sector-level market data to investigate relative performance and sector leadership.

The analytical workflow includes:

Importing historical market data.

Cleaning and transforming the data.

Organizing sector and date information.

Calculating annual sector returns and rankings.

Developing historical performance visualizations.

Creating dynamic return measures.

Adding interactive sector and date selection.

Presenting the results through a consolidated Power BI dashboard.
